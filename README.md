# Inoriol Homebrew Tap

Homebrew formulae for Inoriol projects.

## Installation

```bash
brew tap Inoriol/homebrew-tap
brew install --cask <formula>
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `comquad` | Docker Compose-like CLI for Podman Quadlets and systemd |

## Requirements

- Homebrew (Linuxbrew for Linux packages)
- Most packages require Linux
